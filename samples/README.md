# samples

`talk.mp4`: a 6-second synthetic 9:16 clip (colour bars, a "SAMPLE" label and a speech-like tone with two pauses) for
trying the commands in the help and README, e.g. `ai-video-editor samples/talk.mp4 -o out/`. It is not real
footage: there is no face and no words, so captions come out empty and there is little to cut. Use your own video for
a real edit.

CC0 (see `LICENSE`). Regenerate it with `./samples/make-talk.sh` (ffmpeg only).
